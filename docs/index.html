02 Routing performance

Random

Selects one of the four candidate models uniformly at random for each task.

KNN

Predicts a model from neighboring task embeddings, trained jointly across datasets with grouped five-fold evaluation. Training labels select the cheapest successful model, or the cheapest model if all fail.

Zero-shot LLM

Receives the full task prompt, available task metadata (dimension, difficulty, language and evaluation method), candidate model descriptions, and input/output token prices expressed on the dataset’s normalized cost scale. It selects a model without examples, task answers or correctness labels.

Agent-as-a-Router

Combines task and candidate information with training-fold performance memory and exploration. Memory is updated with the selected model’s benchmark score after each task group, so this is an online feedback evaluation.

Perf / Cost

Perf / Cost divides the successful completion rate (Perf) by mean per-task normalized cost, including solver costs and routing fees scaled by the same range. To align cost scales across datasets, solver costs use per-dataset min–max normalization across eligible task–model pairs: c′ = (c − min) / (max − min), mapping them to [0, 1].

Macro-F1

Compares routing choices against each task’s ground-truth label: the cheapest successful model, or the cheapest model if all fail (cost ties use alphabetical model aliases). F1 is averaged equally over the four model labels; both headline metrics are then averaged equally across datasets.
